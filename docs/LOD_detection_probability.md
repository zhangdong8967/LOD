# 医学检验 LOD 评估中的重复实验与检出概率

> 本文说明：在评估监测试剂检测下限（Limit of Detection, LOD）时，如何通过重复实验与概率论量化“至少检出一次”的可靠性，并解释实践上常取 **20 次重复** 的数学依据与局限。

---

## 1. 问题背景

在医学检验领域，评估试剂或方法的 **检测下限（LOD）** 时，往往需要在接近极限浓度的样本上反复检测。由于单次检测存在随机性（样本变异、仪器噪声、反应波动等），仅凭一次“检出”或“未检出”难以判断方法是否真正可靠。

一个自然的可靠性问题是：

> 若每次独立实验的 **单次成功率** 为 \(p\)，进行 \(n\) 次重复后，**至少有 1 次检出** 的概率是多少？

这直接关系到：我们要重复多少次，才能在统计意义上“相信”一次 LOD 附近的阳性结果。

---

## 2. 数学机制：从伯努利试验到互补概率

### 2.1 单次实验模型

假设每次检测可建模为 **伯努利试验**：

- 成功（检出）：概率 \(p\)
- 失败（未检出）：概率 \(q = 1 - p\)

各次试验 **独立**（这是核心假设；实际操作中需通过独立取样、独立反应孔等尽量满足）。

### 2.2 “至少一次成功”的概率

\(n\) 次试验中 **全部失败** 的概率为：

\[
P(\text{全失败}) = (1-p)^n
\]

因此 **至少一次成功**（即“至少检出一次”）的概率为：

\[
P(\text{至少一次成功}) = 1 - (1-p)^n
\]

这与二项分布一致：\(X \sim \mathrm{Binomial}(n, p)\) 时，\(P(X \geq 1) = 1 - P(X=0)\)。

### 2.3 特例：\(p = 0.9\)

当单次成功率较高（例如 \(p=0.9\)）时，重复带来的增益非常明显：

| 重复次数 \(n\) | \(P(\text{至少一次成功})\) |
|----------------|---------------------------|
| 3 | \(1 - 0.1^3 = 0.999\) |
| 5 | \(1 - 0.1^5 = 0.9999\) |
| 6 | \(1 - 0.1^6 \approx 0.999999\) |
| 10 | \(1 - 0.1^{10} \approx 1\) |
| 20 | \(1 - 0.1^{20} \approx 1\) |

可见：在 \(p=0.9\) 时，即使只重复 3～4 次，检出概率已极高；但 **目标检出率** 与 **实际 \(p\)** 未知时，需要更一般的反推公式。

---

## 3. 反问题：为达到目标检出率需要多少次重复？

给定目标 \(P_{\text{target}}\)（如 95%、80%、50%），解方程：

\[
P_{\text{target}} = 1 - (1-p)^n
\]

得：

\[
(1-p)^n = 1 - P_{\text{target}}
\]

\[
n = \frac{\ln(1 - P_{\text{target}})}{\ln(1-p)}
\]

对 \(p=0.9\)：

| 目标检出率 | 所需 \(n\)（连续解） | 实际操作次数（向上取整） |
|------------|---------------------|--------------------------|
| 50% | \(\ln(0.5)/\ln(0.1) \approx 0.30\) | **1** |
| 80% | \(\ln(0.2)/\ln(0.1) \approx 0.70\) | **1** |
| 95% | \(\ln(0.05)/\ln(0.1) \approx 1.30\) | **2** |

> **注意常见笔误**：若误将 \(\ln(0.1)\) 当作 \(0.1\)（而非正确的 \(-2.303\)），会算得
> \(\ln(0.05)/0.1 \approx 29.93\)、\(\ln(0.2)/0.1 \approx 6.02\)、\(\ln(0.5)/0.21 \approx 3.32\)——
> 这与正确结果相差很大。在 \(p=0.9\) 时，单次试验成功率已达 90%，故 **极少重复** 即可满足 50%～95% 的“至少一次成功”目标。

**解读**：

- 当 \(p=0.9\) 时，**1～2 次重复** 在数学上已足以达到 95% 的“至少一次检出”把握。
- 实践中仍常取 **20 次重复**，原因通常 **不是** 上述公式在 \(p=0.9\) 下的直接结论，而是：
  1. LOD 附近真实单次成功率 \(p\) 往往 **远低于 0.9**（监管定义下 LOD 浓度处检出率常约 50%）；
  2. 需满足 **\(k\) 次阳性** 等更严格判读（非“至少 1 次”）；
  3. 样本非独立、批次效应使 **有效 \(p\)** 低于名义值；
  4. 在 \(p\) 较低时提供 **安全余量**（见下节对照表）。

当 **单次成功率较低**（更贴近 LOD 真实情形）时，所需重复次数显著增加：

| 单次成功率 \(p\) | 目标 95% 所需 \(n\) | 目标 80% 所需 \(n\) | 目标 50% 所需 \(n\) |
|------------------|---------------------|---------------------|---------------------|
| 0.9 | 2 | 1 | 1 |
| 0.5 | 5 | 3 | 1 |
| 0.3 | 8 | 5 | 2 |
| 0.1 | 30 | 16 | 7 |

## 4. 深层次的抽样概率机制

### 4.1 互补事件视角

“至少一次成功”的本质是 **避免连续 \(n\) 次独立失败**。检出概率上升，等价于“全失败”概率 \((1-p)^n\) 的 **指数衰减**：

- 每增加 1 次重复，全失败概率乘以 \((1-p)\)；
- 当 \(p\) 较大时，\((1-p)\) 很小，衰减极快，故少量重复即可显著提高检出率。

参见项目生成的图 `fig5_failure_decay.png`：蓝线为检出概率，红虚线为全失败概率（对数坐标）。

### 4.2 与二项分布及 LOD 判读的关系

在更一般的 LOD 研究中，\(n\) 次重复中成功 \(k\) 次，可用二项分布：

\[
P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}
\]

监管或方法学指南有时规定：在 LOD 浓度下 **\(n\) 次中至少 \(k\) 次阳性** 才判为方法可达 LOD。本文的“至少 1 次”是最简情形（\(k=1\)）。推广形式为：

\[
P(X \geq k) = \sum_{i=k}^{n} \binom{n}{i} p^i (1-p)^{n-i}
\]

### 4.3 蒙特卡洛与“抽样”直觉

解析公式假设已知 \(p\)。实际工作中 \(p\) 由历史数据或 pilot 实验估计。可用 **蒙特卡洛模拟** 验证：

1. 对每次“宏观实验”：模拟 \(n\) 次伯努利试验；
2. 若成功次数 \(\geq 1\)，记为“该次宏观实验检出”；
3. 重复大量宏观实验，估计检出比例。

模拟结果与 \(1-(1-p)^n\) 在样本量足够时一致（见 `fig4_monte_carlo.png`）。这说明了 **重复实验的本质**：用多次独立抽样降低“偶然全阴”的风险。

### 4.4 独立性与有效 \(p\)

模型成立的前提是 **独立性**。以下因素会使有效 \(p\) 偏离理想值或破坏独立：

| 因素 | 影响 |
|------|------|
| 样本不均一 | 同一份样本多次检测，阳性率相关，有效 \(n\) 小于名义 \(n\) |
| 批次效应 | 同一试剂批、同一操作者，失败可能系统性相关 |
| 浓度低于 LOD | 真实 \(p\) 很小，需更多重复才能达到高 \(P_{\text{target}}\) |
| 仪器漂移 | 时间序列相关，非独立 |

因此，“20 次重复”在 **\(p\) 被低估** 时可能仍不足；在 **\(p\) 很高** 时则绰绰有余。热力图（`fig3_required_n_heatmap.png`）展示了 \(p\) 与目标检出率联合决定所需 \(n\)。

## 5. 现实现状与工程权衡

### 5.1 代码实现

本项目 `lod_detection_analysis.py` 提供：

| 功能 | 说明 |
|------|------|
| `prob_at_least_one(p, n)` | 计算 \(1-(1-p)^n\) |

| `monte_carlo_at_least_one` | 蒙特卡洛验证 |
| 五张图表 | 见 `figures/` 目录 |

运行方式：

```bash
pip install -r requirements.txt
python lod_detection_analysis.py
```

### 5.2 实践建议（在理想独立伯努利假设下）

1. **先估计或假定 LOD 附近的单次成功率 \(p\)**（来自验证实验或文献）。
2. **选定目标可靠性 \(P_{\text{target}}\)**（如监管要求的 95%）。
3. **用反解公式计算 \(n\)**，向上取整。
4. **加入安全余量**：考虑 \(p\) 的不确定性、非独立性，可略高于理论值。
5. **成本约束**：重复过多增加时间与试剂成本；\(p=0.9\) 时取 20 次是 **高 \(p\) 情形下** 兼顾把握与成本的常见选择，而非普适常数。

### 5.3 障碍与未知

- 真实 LOD 实验往往涉及 **连续浓度、Probit/Logistic 拟合**，而非单一 \(p\)。
- **假阳性、假阴性** 需用更完整的检测性能模型（灵敏度、特异性）描述。
- 小样本下二项精确推断应使用 **Clopper-Pearson 区间** 等，而非仅点估计 \(p\)。

## 7. 小结

| 概念 | 公式或结论 |
|------|------------|
| 核心公式 | \(P(\text{至少一次成功}) = 1 - (1-p)^n\) |
| 反解重复次数 | \(n = \ln(1-P_{\text{target}}) / \ln(1-p)\) |
| \(p=0.9\)，95% 把握 | 约 **2** 次（非 30 次；30 次对应的是 \(p \approx 0.1\) 的情形） |
| \(p=0.9\)，实践常用 20 次 | 远超公式需求，适用于更低 \(p\) 或更严判读 |
| 深层机制 | 避免 \(n\) 次独立全失败；\((1-p)^n\) 指数衰减 |

概率论与数理统计中的 **伯努利试验、二项分布、互补事件** 为 LOD 重复实验设计提供了清晰框架；将其与实验设计、成本及样本独立性一并考虑，才能在方法与监管要求之间取得平衡。
