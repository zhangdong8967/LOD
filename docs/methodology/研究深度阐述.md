# 研究立意：LoD 重复次数设计（给作者）

**核心问题：** 在明确检测 claim（E1/E2/E3）和效应量下，**LoD 验证需要多少次重复**才在统计上站得住？

**不在范围内：**

| 概念 | 关系 | 本文 |
|------|------|------|
| **LoB** | 空白信号；连续 EP17 路径会用到 | **不是研究对象**（软件可选模块） |
| **LoQ** | 定量下限、CV% | **不是研究对象**（Supplement / LoQ 可选） |
| **LoD** | 能否在低浓度**检出** | **唯一主文焦点** |

完整 scope：[`LOD_RESEARCH_SCOPE.md`](LOD_RESEARCH_SCOPE.md)

---

## 逻辑链

```
方案里的检测 claim
  → E1 / E2 / E3
  → 对该 claim 的 n 与 OC（功效、精确 Fisher）
  → 小样本精确确认
  → tier-A hit-rate 数据（qPCR、probit、RMN）说明 folklore n=20 不足
```

---

## 三个主文失败模式（各一个数）

1. **E2：** 90% vs 80%，\(n=20\) → Fisher 功效 **0.07**；80% 功效 → **\(n\approx199\)**/臂  
2. **E1：** 20/20 全阳 ≠ \(p\ge0.95\)  
3. **P1：** 比较试剂勿用 \(1-(1-p)^n\)（饱和）

**不要**把参数 LoB 失配（P5/P17）写进主文立意——那是连续/空白路径，不是「检测下限重复次数」问题。
